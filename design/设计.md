# 二、改造目标

将现有项目从“大型单文件页面”重构为结构清晰的桌面客户端。

目标效果：

* 保留酷安社区气质。
* 使用现代桌面应用布局。
* 高信息密度但不拥挤。
* 支持浅色和深色模式。
* 支持 Windows、macOS、Linux。
* 主要适配 Windows 11。
* 首页采用三栏结构。
* 评论默认使用右侧抽屉。
* 设置采用标准桌面设置页布局。
* 所有现有真实 API 继续正常工作。

产品体验参考：

* 酷安的品牌与社区内容
* Telegram Desktop 的桌面效率
* X/Twitter 的信息流结构
* Linear 的视觉精度

这里只借鉴布局原则和设计语言，不复制第三方品牌内容。
