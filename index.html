SECURITY & PRIVACY

纯粹、安全与隐私承诺

恪守开源极客精神，尊重用户隐私，将数据控制权完整交还于您。

本地加密持久化

登录凭据与 Cookie 仅保存在本地 Tauri Stronghold 加密库中。客户端没有中央服务，绝不上传凭据至任何第三方开发者服务器。

每次客户端冷启动时会动态生成临时随机设备标识，不抓取用户主机的真实物理硬件指纹，极大程度保障设备私密性。

所有代码在 GitHub 完全公开且经过严格自动化类型与单元测试。每个安装包均由 GitHub Actions 官方纯净环境自动编译。

FAQ

常见问题与解答

有疑问？这里汇总了用户最常咨询的使用要点。

必须登录酷安账号才能使用吗？
完全不需要。公开浏览功能（包括首页信息流、热榜、热门动态、查看图文详情、评论区阅读、数码选机库、话题广场等）无需登录即可自由畅享。只有在进行点赞、收藏、发布动态、楼中楼回复及私信等互动行为时，才需要在客户端内登录。
官方网页授权登录与 Cookie 导入有什么区别？
客户端首选推荐「官方授权登录」，它会调起酷安官方安全登录页面（account.coolapk.com），支持微信扫码与短信验证码登录，安全省心；「Cookie 手动导入」则是备用机制，当您的系统环境 WebView2 授权弹窗受限时，可通过浏览器抓取 Cookie 快速导入。
为什么相比 Electron，Tauri 2 客户端启动更快、体积更小？
Electron 会给每一个应用打包一整个 Chromium 浏览器内核和 Node.js 运行时，安装包通常在 150MB 以上，启动后常驻内存轻松突破 300MB~600MB。而 Tauri 2 直接复用操作系统的原生 WebView 引擎（如 Windows 的 WebView2、macOS 的 WebKit），并结合编译型语言 Rust 处理系统级能力与网络请求，使安装包压缩到仅数十兆，内存占用降至 ~50MB 左右。
Windows 单文件版与安装版有什么不同？
安装版提供系统开机启动选项、开始菜单与桌面快捷图标，并在发布新版本时支持原位静默检测升级；单文件版则是单个独立绿色可执行程序（.exe），不写入注册表，适合放在 U 盘随时携带，两者核心功能与性能表现完全一致。
遇到某些动态无法加载或接口报错怎么办？
本项目调用酷安官方网络接口。部分接口可能受酷安服务器策略、请求频率限制、账号风控或接口调整产生临时波动。若遇到异常，可尝试在左下角设置中清理应用缓存、重新登录账号，或在 GitHub Issues 提交反馈。
